# Credits

This project is our own implementation, inspired by these open-source projects:

- **8mb.local** — `JMS1717/8mb.local` — target-size compression, GPU encoding, queue/history ideas
- **ffmpeg-web** — `dinoosauro/ffmpeg-web` — audio/image conversion, filters, merge, metadata UI ideas
- **ffmpeg-commander** — `alfg/ffmpeg-commander` — preset picker and URL-shareable settings ideas (MIT)
- **HBBatchBeast** — `HaveAGitGat/HBBatchBeast` — batch conversion and folder-watching ideas

We borrow UI patterns and feature ideas, not source files. Check each project's license before copying any code.
